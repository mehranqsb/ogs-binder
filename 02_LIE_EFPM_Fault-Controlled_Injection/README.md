# Fault-controlled injection — LIE and EFPM

Copied from `OGS_Course_2026/02_LIE_EFPM_Fault-Controlled_Injection`.

Open `02_lie_efpm_injection.ipynb` and select **Run → Run All Cells**.
The notebook generates the meshes and projects, runs the single-fracture LIE
and EFPM cases and the double-fracture EFPM case, and plots comparisons.

The first code cell selects this directory automatically. Shared dependencies
and Binder launch links are in the repository root. Generated outputs go into
the `_out_*` directories below `SingleFractureMedium` and
`DoubleFractureMedium`. Previous outputs and Python caches are not included.

The notebook has been checked for syntax and working-directory setup; a full
simulation in Binder has not yet been verified.
